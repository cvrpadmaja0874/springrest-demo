4. Working Jenkins Pipeline Script (Pipeline script mode)

Configured inside springrest-demo-cvrp > Configure > Pipeline (Definition: Pipeline script):
groovy
pipeline {
    agent any

    environment {
        IMAGE_NAME = "cvrpadmaja0874/springrest-demo"
        DOCKER_CREDS = credentials('dockerhub-cvrp')
        CONTAINER_NAME = "springrest-container-cvrp"
    }

    stages {
        stage('Clone Public Repo') {
            steps {
                git branch: 'main', url: 'https://github.com'
            }
        }

        stage('Build JAR') {
            steps {
                sh 'chmod +x mvnw && ./mvnw clean package -DskipTests'
            }
        }

        stage('Build Docker Image') {
            steps {
                sh "docker build -t ${IMAGE_NAME}:${BUILD_NUMBER} -t ${IMAGE_NAME}:latest ."
            }
        }

        stage('Push to Docker Hub') {
            steps {
                sh 'echo $DOCKER_CREDS_PSW | docker login -u $DOCKER_CREDS_USR --password-stdin'
                sh "docker push ${IMAGE_NAME}:${BUILD_NUMBER}"
                sh "docker push ${IMAGE_NAME}:latest"
            }
        }

        stage('Deploy Container') {
            steps {
                sh '''
                    docker stop ${CONTAINER_NAME} || true
                    docker rm ${CONTAINER_NAME} || true
                    docker run -d --name ${CONTAINER_NAME} -p 8086:8082 ${IMAGE_NAME}:latest
                '''
            }
        }
    }

    post {
        always {
            sh 'docker logout'
        }
    }
}
Use code with caution.

5. Day-to-Day Workflow When Updating Your App

1. Edit your Java code (e.g., adding products/coupons to your LinkedList).
2. Push changes to GitHub:bash
git add .
git commit -m "Describe your change"
git push
Use code with caution.
3. Open Jenkins -> go to springrest-demo-cvrp -> click Build Now.
4. Verify your updated image tag on Docker Hub and test your live API via Swagger UI (http://localhost:8086/swagger-ui/index.html).

6. Key Lessons & Troubleshooting Notes

• lstat /target: no such file or directory: Always run ./mvnw clean package -DskipTests before docker build so the .jar file exists for the Dockerfile to copy.
• docker login requires at most 1 argument: Put only your Docker Hub username (cvrpadmaja0874) in the Jenkins credential Username field—never a full command.
• port is already allocated / address already in use: On a shared VM, map your container to an unused host port (like 8086:8082) instead of a port another container is already using.
• In-memory LinkedList data: Items added via Swagger POST work while the container runs, but reset when the container restarts. Add permanent items directly in your Java code before pushing to GitHub.
• Security cleanup: Revoke your Docker Hub Access Token on ://docker.com once your training lab ends.
